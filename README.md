# Chez ya Nathy

Application de commande de Chez ya Nathy : cuisine congolaise en livraison et à emporter
(région lyonnaise), avec un tableau de bord pour la cuisine.

Next.js 16 · TypeScript · Tailwind CSS v4 · Supabase · Stripe · Resend · Vercel.

## Démarrer

```bash
npm install
npm run dev
```

L'app tourne sur http://localhost:3000. Les variables d'environnement à renseigner dans
`.env.local`, l'arborescence, la direction artistique, les règles d'architecture et les
migrations sont décrites dans [STRUCTURE_PROJET.md](./STRUCTURE_PROJET.md).

## Commandes utiles

```bash
npm run build   # build de production
npm run lint    # ESLint
```
